What You Will Learn

Everything it takes to ship a real agent.

Eleven areas, all taught inside projects you build yourself. No theory dumps, no filler.

01

Thinking Like an Agent Architect

How to ideate, scope and architect an agentic solution before you start building. Breaking a real business problem into agent responsibilities, choosing the right pattern for the job, and mapping the flow from trigger to output.

02

Building With Agentic Coding Tools

Practical, hands-on use of Claude Code, Codex and Antigravity. Not tool tours, actual workflows: how to plan, prompt and ship real features, and how to stay in control of what gets built.

03

Prompt Building and Structuring

Writing prompts that produce reliable, repeatable behaviour in production. Structuring context, controlling output format, handling edge cases, and cutting cost without losing quality.

04

Tool Integrations Using APIs

Giving your agent hands. Authentication, rate limits, pagination, error handling. Wiring any third-party API into your agent as a tool it can actually use, and getting it to pick the right tool at the right moment.

05

Production-Grade RAG

Building retrieval systems that hold up in the real world. Chunking strategy, embeddings, vector storage, retrieval quality, and grounding your agent in real data so it stops guessing.

06

MCP Servers and the CLI

Connecting your agent to real systems using the Model Context Protocol. Using existing MCP servers, building your own, and working fluently through the CLI.

07

Building Agent Skills

Packaging capabilities as reusable skills. Designing, building and registering custom skills, then chaining them so your agent handles multi-step work independently.

08

Challenging Cloud API Setups

The setups that stop most builders cold. Developer accounts, verification flows, webhooks, permissions and platform-specific traps. We do the hard configuration together so you never get stuck alone on it.

09

Engineering for Production

Turning a working build into a system you can trust. Error handling, retries, logging, monitoring, guardrails and cost control. This is what clients actually pay for.

10

Database, Hosting and Deployment

Persisting conversation history, user data and agent state. Choosing the right database, managing secrets, hosting on a cloud server, and running your agent 24/7 with zero manual intervention.

11

Portfolio and Getting Clients

Turning everything you built into proof. Spotting high-value use cases, pricing and pitching agent work, where businesses are actively looking, and how to close your first client.
